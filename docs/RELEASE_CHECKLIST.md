# Release checklist

- [ ] Unit tests pass.
- [ ] Skill consistency check passes.
- [ ] All public cases pass strict validation.
- [ ] New rules include a regression case and counterexample.
- [ ] Gender, income, and narrator role swaps were considered.
- [ ] No private identifiers or unauthorized real material are present.
- [ ] Safety changes preserve the fact-assessment/safety-action split.
- [ ] `pyproject.toml`, `CHANGELOG.md`, and the release tag use the same version.
- [ ] Release notes distinguish verified changes from planned work.
- [ ] Metrics contain only publicly verifiable or clearly labeled self-reported values.
