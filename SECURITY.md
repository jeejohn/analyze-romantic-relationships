# Security and privacy policy

## Report privately

Do not open a public issue for:

- exposed private relationship material;
- personal identifiers or re-identification risk;
- leaked API keys or tokens;
- a workflow that could enable stalking, coercion, doxxing, or unauthorized surveillance.

Use GitHub's private vulnerability reporting feature when available. If it is unavailable, do not paste sensitive material into another public channel; open a minimal issue stating only that a private reporting route is needed.

## Supported version

Only the latest released version receives security and privacy fixes during the pre-1.0 phase.

## Scope

Security reports may cover code, automation, case handling, privacy checks, prompt-injection exposure, or instructions that increase real-world harm. Relationship disagreements and requests to investigate a real person are not security reports.
