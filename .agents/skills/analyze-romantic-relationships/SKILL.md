# 情侣关系证据分析

## 核心目标

根据可观察证据评估一段关系呈现出的关爱、真诚、互惠、稳定选择和长期承诺，不直接宣判某人内心“真爱”或“不爱”。

把以下概念分别分析，不混成一个总分：

- 好感、激情与依恋
- 对具体伴侣的关心
- 稳定且符合双方关系约定的选择；只有双方约定排他时才评价排他性
- 婚姻意愿与现实适配
- 经济利益与资源交换
- 履行承诺及共同生活能力
- 关系安全性

对任何实质性案例，读取 [关系证据框架](references/relationship-evidence-framework.md) 和 [分析协议](references/analysis-protocols.md)。遇到单方自述、性别归因、前任、彩礼、收入与陪伴冲突、依恋标签、证据矛盾、安全风险、公众人物视角或绝对化决策口号时，同时读取 [解释与边界规则](references/interpretation-and-boundaries.md)。

用户提供结构化案例文件，或要求建立案例库、审核案例格式、发布案例时，同时读取 [案例数据规范](references/case-data-schema.md)。对本地 JSON 文件先运行 `python3 scripts/validate_case.py <file>`；校验失败时只报告需要修复的字段，不分析被截断或身份信息未清理的材料。普通聊天、自述或截图分析不要求用户先转换为 JSON。

## 先分流任务

先判断用户主要需要什么，不把所有请求都写成长篇关系报告：

- **证据判断**：回答“材料支持什么、不支持什么”。
- **互动循环**：还原反复冲突如何被双方行为持续强化。
- **沟通准备**：在安全前提下，把评价改写为可观察行为、影响、需要与具体请求。
- **决策支持**：比较继续观察、限制新增投入、协商修复、暂停推进或离开的证据与代价；把证据结论转成风险可控的行动规则，但不让启发式反向证明事实或动机，也不替用户作决定。
- **情绪承接**：用户明显受伤或羞耻时，先用一两句承认体验，再进入分析；不要急着说教。
- **安全分流**：出现恐惧、强迫、跟踪、暴力、经济控制、自伤或他伤风险时，先处理安全，不进入普通的“双向沟通”流程。

直接回答用户明确提出的核心问题。只在缺少的信息会实质改变结论或安全建议时提问。

## 处理输入

1. 识别材料类型：聊天原文、截图、转述、自述、行为记录或评论观点。
2. 如果用户分多次发送并表示尚未结束，先确认接收，不提前做完整结论；等用户说明“讲完了”再统一分析。
3. 提醒用户隐去姓名、电话、地址、账号、单位等身份信息；不要在输出中复述无关隐私。
   用户要求把案例加入公开案例库时，必须另外确认材料已经去标识化、具备分析授权和公开授权；“同意分析”不等于“同意公开”。无法确认公开授权时只生成不含原始私密内容的合成案例或结构模板。
4. 建立人物代号、关系阶段和时间线。多人对话不得混淆说话人。
5. 明确双方已约定什么：排他性、金钱性质、联系频率、隐私、家庭分工和婚姻计划；没有材料时不得用传统角色或分析者偏好补齐。
6. 标注材料视角。单方自述只能证明叙述者报告了什么，不能自动证明对方动机。
7. 长材料按“关系阶段与冲突事件”切分，记录说话人、触发、行为、回应和结果；合并重复截图，保留矛盾版本，不把早期与当前状态平均成一个结论。
8. 给关键材料分配 `E1`、`E2` 等证据编号，使重要结论可回溯。同一事件的多张截图、转述和评论默认属于同一证据簇，不重复计权。
9. 先做安全筛查，再绘制双方互动循环。若存在恐惧、报复、强迫或明显权力不对称，先评估可拒绝性和现实危险。
10. 如果缺少决定性上下文，继续完成有限分析，并明确列出缺失信息；只有缺失内容会实质改变任务时才提问。区分“材料未覆盖”“明确没有发生”和“发生后被拒绝或违背”。

## 建立证据账本

用两个轴记录材料，避免把“内容类型”和“来源可靠性”混成一项：

| 内容类型 | 含义 | 能直接支持什么 |
|---|---|---|
| 原始痕迹 | 聊天、转账、日程或完整截图中可定位的内容 | 该内容出现过；不自动证明其真实、完整或已履行 |
| 具体事件报告 | 有时间、场景、言行和结果的当事人或第三方报告 | 某人作出了该报告；对“行为确实发生”只构成标明来源的单一来源证据 |
| 明确表达 | 当事人直接说出的感受、意愿、约定或解释 | 当时表达了什么；不自动证明唯一动机或未来行为 |
| 分析推断 | 根据多项材料提出的关系模式 | 只能作为待检验结论，不能反过来充当证据 |

另行标注来源、时间、上下文完整度、是否独立、是否有旁证及可替代解释。证据质量必须与待证明命题匹配：聊天原文可强力证明“说过什么”，对“是否真实履约”可能很弱；具体行为可支持模式，却通常不能单独证明内心动机。

给重要判断分配 `C1`、`C2` 等结论编号。先标注命题类型，再按《分析协议》执行：命题 → 对应证明门槛 → 支持证据 → 反证 → 材料上可行的替代解释 → 裁决状态 → 证据强度 → 置信度 → 结论边界。固定使用“支持 / 部分支持 / 未获支持 / 与材料矛盾 / 无法判断”作为裁决状态，不用含糊措辞跳过裁决。

稳定模式不能只按事件数量判断。两个相对独立事件通常只能建立候选模式；还要检查观察机会、时间跨度、场景差异、复发比例、趋势和反例，才能提高为稳定模式。但暴力、性强迫、跟踪等单次严重事件已足以触发安全分流。说明证据支持什么、不能证明什么，不把重复材料当作交叉验证。

## 分析流程

1. 按阶段还原关系形成、升温、承诺、冲突、修复或破裂过程，分别说明“曾经如何”和“当前如何”。
2. 确认关系约定、贡献性质和双方是否能安全拒绝；无法确认时标为未知。
3. 先筛查暴力、强迫控制、跟踪、恐惧和现实报复。通过安全门槛后才使用普通冲突循环和共同沟通方案。
4. 分别评价 A 与 B，不把一方的投入自动视为双方共同投入。
5. 使用关系证据框架逐项分析：关心回应、尊重边界、言行一致、稳定投入、双向互惠、诚实信任、冲突修复、稳定选择、共同未来和关系安全。
6. 判断投入、关爱、可靠性、承诺和履约时，优先检查行为是否持续、适配真实需要、尊重边界并产生可靠结果；真实成本只作辅助指标，不能让高成本牺牲压过低成本但稳定、精准的照顾。言语仍是判断“表达过什么、约定了什么”的直接证据。言行冲突时并列陈述，并以跨时间、跨场景的重复行为判断当前履约模式，同时考虑能力、情境、机会成本、观察机会与证据是否独立。不要用一次昂贵赠与、猛烈追求或自我牺牲替代长期模式，也不要用这条规则淡化单次严重安全事件。
7. 分开评价情感投入、婚姻意愿、现实利益和履约能力。接受婚姻不等于投入感情；看重条件也不等于完全没有感情。
8. 检查利益工具化与“单向权利型关系”的证据，但先区分赠与、借款、共同开支、明确交换和未说出口的期待；不得仅凭性别、彩礼金额、收入差异或谁支付更多下结论。
9. 检查经济劳动、陪伴、家务、育儿、照护与情绪劳动是否具体发生、被双方看见并公平协商，不把自我宣称的贡献直接记为已被双方认可。
10. 对重复冲突绘制循环：触发 → A 的可观察反应 → B 的影响与反应 → A 的再次反应 → 结果。把推测的感受或需要明确标为假设。
11. 检查人格批评、轻蔑羞辱、防御推责、退避中断等沟通风险，同时区分“暂时降温并约定返回”和惩罚性冷战。
12. 主动寻找反证和材料上可行的替代解释，包括良性、混合或伤害性解释；不要为满足形式而虚构“非恶意解释”。检查条件变化是否与其他压力同时发生。同步变化只支持关联，不自动证明因果或唯一动机。
13. 保持多方视角，但不强求责任对半。理解双方体验不等于把伤害、控制或违约解释为同等责任。
14. 分别给出维度评价、证据强度、裁决状态和结论置信度，不用一个模糊总分替代。证据强度评价材料对当前裁决的区分力，支持证据和反向证据都要计入；裁决状态表示方向。置信度以证据强度为上限，再因未解决的矛盾、混杂、缺失、替代解释及因果、动机或预测的额外不确定性下调，不重复扣减同一缺陷。
15. 只有用户要求时才给沟通、观察或关系改善建议；必要的安全提示不受此限制。先区分“材料证明了什么”和“在不确定下怎样控制风险”，再给直接表达、观察互惠、限制新增投入或退出等选项；不要把建议、口号或决策启发式伪装成诊断和事实结论。

## 判断经济与陪伴冲突

不要把问题简化为“高收入者已经尽责”或“需要情绪价值者不知足”。分别确认：

- 高收入是否确由长期劳动、风险或机会成本换来；
- 金钱或资源是赠与、借款、共同开支还是明确交换，回报期待是否事先说清并获得同意；
- 付出相对各自能力、共同受益程度和可替代选择如何；未表达的期待不得事后自动变成对方债务；
- 忙碌是阶段性安排还是长期生活方式；
- 经济贡献是否被用作退出陪伴、家务、育儿或尊重义务的免责权；
- 陪伴需求是否具体、可协商，还是无限且不可满足；
- 双方是否同时要求高收入、高可支配时间和单方承担家庭责任；
- 是否存在稳定、可预期的最低联系、重要时刻在场和冲突修复；
- 双方是否承认对方不同形式的贡献，并愿意共同承担调整成本。

把解决方向落到明确的关系契约：经济、时间、家务、照护和情绪劳动由谁承担，最低标准、期限、失约后的补救及重新协商方式是什么。

## 结论边界

- 使用“现有材料支持……”“一种合理解释是……”和“证据不足以确定……”。
- 使用“材料中未出现”时，同时说明它可能只是未被提供；只有时间线明确覆盖且确实未发生时，才写“在该期间未发生”。
- 只陈述自己能观察到的行为和影响，不替任何一方宣称隐藏意图、潜台词、童年创伤或“真正需要”。
- 当事人明确说出的动机，是“其表达过该动机”的直接证据；除非材料足以排除混合动机，不写成其唯一或真实全部动机。
- 不根据回复慢、话少、性格冷淡、一次争吵或一次经济分歧直接判断不爱、出轨、操控或人格问题。
- 不根据少量聊天给任何一方判定依恋类型、防御机制、认知障碍或神经系统状态；可以描述“追逐—退缩”等互动模式，并标明证据。
- 不把联系前任自动等同于复合或出轨；分析联系内容、隐瞒程度、边界约定和后续修复。
- 不默认所有关系都以排他、结婚、合并财务或固定性别分工为目标；以双方明确约定为基线。
- 不因进入婚约就推定有爱情，也不因婚姻含经济考虑就推定关系虚假。
- 不把高额金钱付出自动等同于更深感情；同时评价时间、照顾、情绪支持、家务、育儿和机会成本。
- 不把自愿赠与或未经协商的单方牺牲自动转换成感情债务；同时检查是否存在诱导、欺骗、默认规则或拒绝边界后的持续索取。
- 不把“信号模糊”直接写成“内心不喜欢”。在已经清楚、低压力地表达并给予合理回应时间后，长期缺少稳定互惠行动只支持“兴趣或承诺尚未建立”，可据此限制新增高成本投入。
- “给台阶”只能表示提供真实、低压力且允许拒绝的选择或退出空间；不得虚构理由、设计圈套、反复纠缠或绕过明确拒绝。
- 保持性别对称：无论男女，长期只索取权利、不承担责任都属于风险。
- 不诊断抑郁症、人格障碍、依恋障碍等疾病，不断言无法观察的真实动机。
- 不把关系分析写成司法鉴定、临床诊断、出轨证明或公开指控；涉及法律、医疗或取证结论时明确转交相应专业渠道。
- 发现羞辱、威胁、跟踪、强迫、经济控制、孤立、自伤或他伤风险时，优先处理安全，不把它仅描述为普通沟通问题，也不建议用户独自对质或用共同沟通练习解决强迫控制。

## 输出格式

根据任务和材料规模选择结构，避免为了完整而机械拉长。短问题优先使用“结论—证据—限制—下一步”；完整证据报告使用：

1. **综合判断**：用一段话回答用户核心问题，并说明证据强度。
2. **材料与视角限制**：说明数据来源、缺口和单方视角。
3. **关键时间线**：仅列影响判断的转折。
4. **双方维度对照**：分别评价 A、B，必要时分阶段，使用“较强 / 中等 / 有限 / 风险突出 / 证据不足”。
5. **互动循环**：有重复冲突时，用行为链说明双方如何相互强化，不写成性格判决。
6. **支持证据与反证**：区分关系投入、利益因素、承诺和风险。
7. **言行一致与互惠结构**：说明贡献是否被承认、回馈和公平协商。
8. **其他合理解释与区分信息**：列出替代假设，以及什么新信息能区分它们。
9. **裁决与置信度**：为关键命题标明类型、裁决状态、证据强度和置信度；分别陈述关系模式、具体事件解释、因果、动机和预测的边界。
10. **建议**：仅在用户要求时提供具体、可验证且符合安全级别的沟通、观察或决策方案；发现现实安全风险时始终给出最低必要安全提示。

不要只输出一个“真爱分数”。如果用户坚持要量化，先提供维度分数和证据，再说明总分不能验证内心。

## 输出前检查

- 是否先回答了用户真正的问题，而非展示全部框架？
- 每个重要结论能否回指证据，是否把推断写成了事实？
- 每个重要结论是否标明命题类型、适用门槛和五种裁决状态之一？
- 证据是否真正适合该命题，重复截图或同源转述是否被错误算成多项独立证据？
- 是否把“某人报告发生了某事”误写成“该行为已经证实”，或因事件尚未核实而漏掉必要的预防性安全提示？
- 是否把“材料没提供”误写成“从未发生”，或把当事人的表达误写成已经履行？
- 是否把感受、意图、婚姻意愿、经济适配和履约能力混在一起？
- 是否按关系阶段呈现变化，并以双方真实约定而非默认单偶、婚姻或性别角色为基线？
- 是否寻找了反证、时间趋势和条件变化，而非只挑支持用户立场的材料？
- 交换性别、收入或叙述者身份后，证据标准是否仍一致？
- 是否把相互冲突误写成强迫控制，或把强迫控制误写成普通沟通问题？
- 是否把自愿赠与、未明说期待或单方高成本选择误写成对方欠债？
- 稳定模式是否检查了观察机会、时间跨度、场景差异、复发比例、趋势和反例，而不只计算事件数量？
- 置信度是否受证据强度约束，并对反证、混杂和替代解释作了可说明的下调？
- 是否把用于控制投入的决策启发式误写成对方内心状态，或用“体面”包装欺骗与绕过拒绝？
- 建议是否为用户明确要求、能够执行，并与风险级别匹配？
