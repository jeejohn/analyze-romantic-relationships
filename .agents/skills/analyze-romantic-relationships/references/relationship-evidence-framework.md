## 1. 真爱拆解

不要把“真爱”当成可由一句话验证的心理状态。分别评估：

- **感情存在**：是否有好感、想念、依恋、亲密和关注。
- **关爱能力**：是否关心对方作为一个人的感受、困难、尊严和成长。
- **稳定选择**：面对替代选择、冲突和压力时是否持续遵守双方约定；只有约定排他时才评价排他性。
- **稳定承诺**：是否愿意承担长期责任并兑现承诺。
- **成熟互惠**：是否能看见双方贡献、接受边界并共同修复。
- **婚姻适配**：价值观、生活方式、经济安排和家庭责任是否兼容。

“爱过”“适合结婚”“能够忠诚履约”必须分别判断。

## 2. 十项关系维度

| 维度 | 支持证据 | 风险证据 |
|---|---|---|
| 关心与回应 | 主动了解感受和困难，在重要时刻提供适当支持 | 只在需要资源时出现，长期忽视对方处境 |
| 尊重与边界 | 接受拒绝、隐私和独立空间，不惩罚合理边界 | 监控、强迫、羞辱、以分手威胁服从 |
| 言行一致 | 承诺与实际行为大体一致，失约后主动补救 | 反复承诺但不行动，解释随利益变化 |
| 稳定投入 | 持续投入时间、精力、责任和机会成本 | 只有关系顺利或有收益时才投入 |
| 双向互惠 | 双方以不同但被认可的方式贡献和回馈 | 长期单向索取，付出者表达困难仍被加码 |
| 诚实与信任 | 重要信息坦诚，错误后愿意说明并重建信任 | 隐瞒、欺骗、双重标准、反复试探 |
| 冲突修复 | 倾听、承担责任、道歉、调整并验证改善 | 冷战、翻旧账、推责，问题反复且无改变 |
| 稳定选择 | 在压力、替代选项和条件波动时仍遵守关系约定 | 隐瞒与前任或其他对象的越界行为，或遇到小挫折即撤回承诺 |
| 共同未来 | 共同讨论并落实双方认可的未来安排 | 只享受当下利益，长期回避责任与规划 |
| 关系安全 | 没有恐惧、控制、暴力或剥夺基本自主 | 威胁、跟踪、孤立、经济控制、性强迫或暴力 |

对每一维分别评价 A、B。没有材料时写“证据不足”，不要用整体印象补齐。

## 3. 命题与证据匹配

不存在对所有问题都适用的固定证据排行榜。先写清要判断的命题，再选择适合它的证据：

| 待判断命题 | 较直接的证据 | 常见越界推断 |
|---|---|---|
| 某人报告了什么 | 该人的原始自述、可定位的转述记录 | 从“有人这样报告”直接推出“报告中的行为已被证实” |
| 说过什么、提出过什么约定 | 连续原始对话、完整录音或双方认可的记录 | 从“说过”直接推出“真实相信”或“已经履行” |
| 某次行为是否发生 | 可核对记录、双方一致报告、有时间和结果的具体自述；单方自述必须保留来源和未核实状态 | 把单方报告省略来源后写成既定事实，或因未独立核实而假定报告必然虚假 |
| 某人当时的感受或意愿 | 当事人的直接表达，并结合前后语境 | 把一次表达写成长期、唯一或不变的内心状态 |
| 承诺和履约能力 | 约定、实际行动、失约后补救及复发情况 | 用甜言蜜语或一次高成本行为替代长期履约 |
| 稳定关系模式 | 相对独立事件、相关观察机会、时间跨度、场景差异、复发比例、趋势和反例 | 只因出现两次就断言长期稳定，或将同一争吵的多张截图重复计权 |
| 条件之间的因果 | 时间顺序、重复对照、可行机制和主要混杂因素是否被削弱 | 把同步变化直接写成单一原因 |
| 内心动机 | 直接且持续的自我表达与一致行为 | 从行为结果反推唯一动机，或把混合动机压成“只为钱/完全不爱” |
| 未来预测 | 已建立的既有模式、条件是否持续及真实修复结果 | 把过去行为写成必然复发或永久人格 |
| 安全风险 | 威胁、跟踪、强迫、暴力、恐惧和拒绝后的报复 | 因为只有一次就淡化严重事件，或把普通分歧自动升级为虐待 |

每项证据按以下属性评估，不只看载体：

- **直接性**：对当前命题是直接材料，还是隔了一层解释；
- **具体性**：是否有时间、场景、原话、行为和结果；
- **完整性**：是否有上下文、前后消息或可能被截断；
- **独立性**：是否来自不同事件或独立来源，而非同一素材的重复；
- **覆盖度**：覆盖哪个关系阶段、持续多久、是否只出现在顺利时期；
- **旁证与反证**：是否有其他来源支持，是否存在重要例外；
- **替代解释**：哪些良性、混合或伤害性解释在现有材料上真正可行；不要机械虚构非恶意解释。

详细命题类型、五种裁决状态和置信度更新规则见 [分析协议](analysis-protocols.md)。单次事件只支持该次行为；两个相对独立事件通常只够建立候选模式。只有结合相关观察机会、时间或场景覆盖、复发趋势和反例后，才提高为稳定模式。

### 行动与言语的比较规则

不要把“行动大于言语”当作对所有命题都适用的固定排序：

- 判断“说过什么、如何定义关系、是否明确约定或拒绝”时，完整语境中的言语是直接证据；
- 判断投入、关爱、可靠性、承诺和履约时，跨时间、跨场景的实际行为通常比单次表达或口头承诺更有证明力；
- 提高行动权重前，优先检查它是否出于自愿、尊重对方边界、实际回应对方需要、产生可靠结果，并在受挫或无即时回报时仍能持续；相对能力下承担的真实成本只作辅助信息；
- 一次转账、昂贵礼物、猛烈追求、公开表态或自我牺牲只能证明该次行为发生，不能自动证明更深的感情；检查交换期待、愧疚补偿、形象经营、控制条件和实际受益者；
- 言行冲突时，写明“表达了什么”和“实际做了什么”。用重复行为判断当前履约模式，不把“说过”写成“做到”，也不从失约直接反推从未有感情或唯一动机；
- 能力限制、突发压力和缺少行动机会可能降低行为的区分力；重点观察是否诚实说明、共同协商、寻找替代方式并在条件允许时补救。

最稳妥的原则是：**言语界定表达与约定，行动检验投入与履约，跨时间的一致性提供最强支持。**

能力有限但稳定尽力，可能比高成本却附带控制条件的付出更能说明关爱。单次严重安全事件不需要重复发生，已经足以采取谨慎的安全措施。

在已经清楚、低压力地表达意愿并给予合理回应时间后，长期模糊或缺少互惠行动可以支持“稳定兴趣或承诺尚未建立”，并据此限制新增高成本投入；它仍不能单独证明对方内心绝无好感、只图条件或提问者缺乏价值。把这种投入上限写成操作规则，不反过来当作动机证据。

## 4. 条件变化测试

不要人为制造危机、突然造访、故意含糊需求或撤回资源来测试关系。用真实目的直接表达，并只利用材料中自然发生的条件变化，例如：

- 收入下降、失业、疾病或家庭压力；
- 异地、忙碌、备考或照护责任增加；
- 彩礼、住房、生育或职业安排进入实际谈判；
- 一方设立合理边界或无法继续原有付出；
- 关系公开、订婚、结婚或共同财务等承诺成本上升。

比较变化前后的关心、尊重、主动性、责任和修复。态度改变可能支持利益工具化，也可能来自压力、能力下降或价值观冲突；结合表达、协商和持续时间判断。

条件变化常与争吵、家庭介入、健康变化或关系阶段升级同时发生。同步变化只能支持关联；只有排除主要混杂因素后，才能谨慎提高因果判断，仍不得据此断言唯一内心动机。

## 5. 利益工具化

经济考虑是婚恋关系的正常组成部分。只有出现一组稳定迹象时，才提高“关系被利益工具化”的可能性：

- 对房产、收入、彩礼、身份或资源的关注显著多于对伴侣本人的关注；
- 只在资源持续提供时表达亲密或承诺；
- 条件下降后迅速撤回尊重、关心或共同承担；
- 隐瞒真实意图，以爱情承诺换取单向资源；
- 拒绝协商权利义务，只要求对方证明诚意；
- 获益后持续回避原先承诺；
- 把伴侣当作可替换的条件组合，而非有边界和需求的人。

同时寻找反证：在条件不利时仍支持、主动承担成本、尊重边界、愿意降低自身收益或持续修复。

先确认资源性质与共同规则：赠与、借款、共同开支、家庭安排、明确交换还是未经说明的单方期待。自愿赠与不能仅因关系结束就被改写为对方欺骗；但若存在虚假承诺、隐瞒事实、诱导投入或拒绝边界后仍持续索取，则应提高风险判断。

## 6. 单向权利型关系

当以下模式长期并存时，判断风险升高：

1. 一方承担主要经济、时间、家务、照护或可具体描述的情绪支持成本。
2. 受益方将这些投入视为无上限义务。
3. 受益方很少认可、协商或以双方认可的方式回馈。
4. 付出方表达困难或设立边界时，受到指责、贬低或感情威胁。
5. 双方适用不同标准。
6. 受益方在利益减少时显著撤回态度与承诺。

不要把“回馈”限定为同等金额。互惠可以是时间、照顾、家务、情绪支持、事业牺牲、风险承担或其他双方认可的贡献。

也不要把付出方未说明的交换期待当成既有契约。检查付出是否自愿、是否能安全停止、双方是否知情同意，以及受益方是否曾拒绝、被迫接受或被告知无需回报。

## 7. 经济与情感贡献

高收入可能代表长工时、责任、风险和机会成本，但不能自动替代：

- 基本尊重和忠诚；
- 重要时刻的可靠在场；
- 最低限度的稳定联系；
- 家务、育儿与照护责任；
- 冲突后的解释和修复。

情绪与陪伴需求也不能自动否定：

- 工作压力和现实资源约束；
- 经济贡献的长期劳动；
- 个人合理的休息和独处边界；
- 双方共同选择的事业目标。

先把贡献写成具体行为，不把“我提供情绪价值”“我负责赚钱”直接当作已完成的贡献。综合评估：

- 付出是否事先协商、自愿且可停止；
- 付出相对个人能力、时间和机会成本的比例；
- 谁实际受益，是否也服务于付出者自己的目标；
- 回报期待是否明确，双方是否同意；
- 是否以付出换取控制、服从或不受约束的特权；
- 对方是否以能力相称、双方认可的方式承担其他责任。

分析双方是否建立了明确、可执行的安排：最低联系频率、固定二人时间、加班告知、重要事件在场标准、家务育儿分工、忙碌期限和目标完成后的调整。

## 8. 婚姻和彩礼分歧

因彩礼、住房或婚礼费用分手不能单独证明多年感情为假。分别考察：

- 双方真实支付能力和家庭压力；
- 钱款用途、归属和婚后风险分担；
- 是否允许协商、折中与透明核算；
- 是否用金额作为爱或服从的唯一证明；
- 双方家庭是否越过当事人自主边界；
- 谈判过程中是否保持尊重、诚实和对等责任；
- 条件变化是否导致对“这个人”的关心同步消失。

将结论写成经济公平、家庭边界和价值观适配问题，不用地域或性别刻板印象代替证据。

不把自由恋爱、相亲、家庭参与、分财或合财、结婚或不婚中的任何一种自动视为更真诚。核心检查自主同意、信息透明、可协商性、权利义务和对真实关系约定的履行。
