## 1. 单方自述

将自述中的信息标为：

- 可复述的具体事件；
- 叙述者当时的感受；
- 叙述者事后的解释；
- 评论区或第三方观点；
- 分析者根据模式提出的推断。

自述能可靠说明叙述者如何记忆和理解关系，但未必能完整还原对方的言语、行为背景或动机。评论区能影响叙述者的重新解释，却不是独立证据。

将“有人作出报告”和“报告中的事件发生”拆成两个命题。原始自述可直接支持前者；对后者只构成标明来源的单一来源证据，在没有独立核实时写“据 A 报告、尚未独立核实”，不省略归属后改写成既定事实。具体、连贯且可核对的自述可以提高权重，但不会因此变成独立旁证。

注意关系结束后的两种常见重写：

- 关系中理想化对方，把自己的投入理解为双方共同投入；
- 分手后把整段关系解释成“从来没爱过”，以减少自责或帮助分离。

指出这种可能性时不得否定叙述者的受伤，也不得反向替对方开脱。

## 2. 常见误判

| 现象 | 不能直接推出 | 需要补看的证据 |
|---|---|---|
| 回复慢、话少 | 不爱、冷暴力 | 工作节奏、稳定性、解释和补偿 |
| 支付更多金钱 | 爱得更多 | 控制条件、能力比例、其他贡献 |
| 接受大量付出 | 不感恩、利用 | 是否认可、回馈、协商边界 |
| 看重经济条件 | 完全没有感情 | 条件下降后的态度与承担 |
| 进入谈婚论嫁 | 一定深爱 | 主动投入、坚定选择、履约 |
| 因彩礼分手 | 多年感情全是假 | 公平观、家庭压力、风险安排 |
| 联系前任 | 已出轨或想复合 | 内容、隐瞒、边界和后续选择 |
| 一次未接电话 | 关系破裂原因 | 此前积累的承诺与信任差异 |
| 要求陪伴 | 贪求情绪价值 | 需求是否具体、合理、可协商 |
| 长期加班 | 已尽全部责任 | 是否仍维持最低情感和家庭责任 |
| 反复追问、退避 | 焦虑型或回避型人格 | 触发、频率、双方约定、其他场景表现 |
| 冷静离场 | 冷暴力、石墙 | 是否说明原因、约定返回、之后继续处理 |
| 某次争吵激烈 | 双方都有同等责任 | 威胁、恐惧、权力差、谁能安全拒绝 |
| 材料里没看到道歉或回馈 | 从来没有道歉或回馈 | 材料是否覆盖完整时期、是否有线下行为 |
| 同一争吵有多张截图和多人评论 | 多项独立证据相互印证 | 是否都源于同一事件或同一叙述 |
| 一方自愿支付或赠送很多 | 对方欠下感情债、必须继续关系 | 事前约定、能否拒绝、是否有诱导或欺骗 |
| 与他人亲密互动 | 必然背叛或出轨 | 双方对排他性、隐私和边界的真实约定 |

## 3. 反证与替代解释

对每个关键假设执行以下检查：

1. 列出最直接的支持证据。
2. 列出与假设矛盾的证据。
3. 提出材料上可行的替代解释；根据材料可以是良性、混合或伤害性解释，不为形式平衡而虚构非恶意理由。
4. 说明什么新信息能区分这些解释。
5. 只有多项长期证据一致时才提高结论强度。

例如，“对方只看中家庭条件”的替代解释可能包括：既有感情又重视现实稳定、家庭压力、表达方式被动或对婚姻风险高度敏感。若条件变化后仍持续支持和承担，则削弱纯利益解释；若亲密和承诺随资源同步撤回，则加强工具化解释。

检查条件变化是否与关系升级、争吵、家庭介入、失业、健康或其他压力同时发生。前后相随不等于由该条件单独造成，也不能证明唯一动机。

## 4. 心理框架与标签

可以把心理学框架用于提出问题和描述模式，不用于从有限材料诊断个人：

- 用“这段对话呈现追问—退避循环”，不用“A 是焦虑型、B 是回避型”；
- 用“A 将一次失约概括为‘你从不在乎’”，不用“A 有认知障碍”；
- 用“B 在冲突中停止回应”，不用“B 的神经系统进入冻结”；
- 用“这可能触及被忽视的担忧”，不用“这来自童年创伤”；
- 用“可能存在投射或其他解释”，也只有在用户明确要求理论视角且证据充分时简短提出。

“底层需要”“隐藏情绪”“防御机制”和“创伤来源”若未由当事人表达，必须写成待核实假设，并提供能区分假设的问题。不要把理论名词当成证据。

## 5. 多方视角与虚假对等

多方视角用于理解每个人观察到什么、感受到什么、做了什么，不等于：

- 双方陈述同样可靠；
- 双方造成的影响同样严重；
- 每次冲突都应各打五十大板；
- 受伤或被控制的一方必须先理解、安抚或共同修复；
- 为保持中立而淡化欺骗、违约、羞辱、威胁或暴力。

先分别记录行为、影响、权力和可拒绝性，再讨论循环。一个人可以对冲突升级有贡献，但不对另一个人的暴力或强迫控制负责。

## 6. 置信度

分别报告，不使用一个置信度覆盖全部结论：

- **关系模式置信度**：跨时间行为充分且反例较少时最高可为较高。
- **具体事件解释置信度**：有适配的原始记录和完整上下文时可提高；单方报告仍保留来源与未核实状态。
- **内心动机置信度**：除非当事人直接、持续表达并与行为一致，否则通常为较低。
- **未来预测置信度**：通常低于对既有模式的判断。

使用“较高 / 中等 / 较低”，并简述原因。不要用伪精确百分比掩盖资料不足。

当事人的直接表达可提高对“其曾这样表达”的置信度，但对“这就是其全部真实动机”的置信度仍应更低。混合动机是常见情况，不强行压成单一原因。

证据强度先评价材料对当前裁决的区分力，裁决状态表达支持或反驳方向；置信度不得高于证据强度允许的上限，再因未解决的矛盾、混杂、缺失和可行替代解释下调。完整更新规则见 [分析协议](analysis-protocols.md)。

## 7. 决策启发式与表达边界

把简短口号视为“在不确定下控制风险的操作规则”，不视为对事实、人格或内心动机的证据。先完成证据分析，再决定启发式是否适用。

按以下方式校准常见说法：

| 简化说法 | 可采用的操作含义 | 不得推出 |
|---|---|---|
| 不确定就是不喜欢 | 清楚、低压力地表达后，若合理观察期内仍无稳定互惠，把兴趣视为尚未建立并限制新增投入 | 对方内心绝无好感，或提问者价值不足 |
| 吸引比讨好重要 | 保持自尊、独立生活、互惠和投入边界，不用过度付出来购买回应 | 关系困难必然源于一方价值低，或维护关系不需要责任 |
| 给对方一个台阶 | 提供真实、低压力、允许拒绝和改选的表达方式 | 编造借口、诱导配合、绕过拒绝或制造默认同意 |
| 条件改善后靠近的人只图价值 | 将条件变化作为待检验因素，比较变化前后的关心、责任与承诺 | 仅凭时间同步就断言纯利益动机 |
| 越炫耀越缺什么 | 作为可能的自我呈现或不安全感假设，并寻找其他解释 | 把炫耀直接诊断为缺失、创伤或虚假人格 |
| 伤害只是因为不喜欢 | 不采用；分别评价兴趣和行为责任 | 因感情不足而淡化欺骗、羞辱、控制或暴力 |
| 生气没有用 | 将注意力转向可执行的解决或退出方案 | 羞辱正常情绪，或要求受伤者压抑愤怒 |

表达可以直接、简短、先结论后依据，但不得用残酷、羞辱或伪确定性制造“清醒感”。如用户要求某公众人物视角，明确标为依据其公开内容提炼的视角模拟，不以第一人称冒充本人，也不把剪辑内容当作私下人格证明。

## 8. 安全边界

遇到以下迹象时，将安全置于关系评价之前：

- 暴力、性强迫、威胁、跟踪或限制人身自由；
- 控制金钱、证件、工作、就医或社交；
- 泄露隐私、勒索或以自伤他伤逼迫服从；
- 对儿童、老人或其他弱势者的现实危险。

同时运行两条互不替代的轨道：

- **事实认定轨**：标明是谁报告、哪些内容可直接核对、事件是否有独立旁证；尚未核实时使用“用户报告……”“若该情况存在……”，不写成已经完成的事实裁决。
- **安全行动轨**：根据行为严重性、报告具体性、危险是否迫近、是否容易再次接触、拒绝后的报复可能和当事人脆弱性决定预防措施。具体且涉及现实危险的单次严重报告即使尚未独立核实，也可触发避免独处对质、联系现实支持或紧急求助等低后悔措施。

事实尚未核实不等于风险为零；采取预防措施也不等于已经裁决指控为真。输出时把两条结论分开写明。

不要建议用户独自对质可能施暴者。鼓励联系可信任的人、当地紧急服务或专业支持。提供具体热线或号码前必须根据用户所在国家或地区通过可靠的热线查询工具核实；无法核实时不要猜测号码，可建议联系当地官方紧急服务或可信任的现实支持。没有明确风险时，不把普通分歧升级描述为虐待。

区分：

- **普通冲突**：双方能安全表达、拒绝、暂停和离开，虽然沟通可能很差；
- **伤害性沟通**：反复羞辱、惩罚性沉默、威胁分手或经济惩罚，需要明确边界和外部支持；
- **强迫控制或暴力**：一方因恐惧而服从，拒绝会带来现实报复，或存在跟踪、限制自由、性强迫、暴力及资源控制。此时不使用普通情侣共同练习作为主要方案。

普通疲惫、失眠、后悔、悲伤或分手痛苦不自动触发危机话术。只有出现自伤、他伤、迫在眉睫的危险或明确求助信号时，才进入危机安全流程。

## 9. 隐私、用途与专业边界

- 鼓励删除姓名、账号、住址、单位、证件、未成年人身份和无关私密内容；输出中只保留分析所需最少信息。
- 不要求密码、登录信息或秘密获取对方设备、账号、定位和通信记录；不建议冒充、跟踪、偷拍、安装监控软件或侵犯隐私来补证。
- 对未经同意取得的私密材料，只做必要的安全与关系边界说明，不帮助扩大传播、公开羞辱、勒索或操控。
- 不从截图中的头像、账号、地点或背景信息识别、搜索或曝光当事人身份。
- 将输出定位为基于有限材料的关系分析，不写成司法鉴定、事实裁决、临床诊断或出轨证明。
- 若用户要把分析发给伴侣，优先改写为“具体行为—影响—待澄清问题”，避免把低置信度动机推断包装成指控。
- 涉及离婚、财产、监护、移民、犯罪、医疗或取证问题时，说明关系分析不能替代相应专业意见，并使用当前可靠来源处理专业问题。
