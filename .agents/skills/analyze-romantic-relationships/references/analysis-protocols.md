## 1. 任务分诊

根据用户目标选择最小充分流程：

| 目标 | 必做 | 不必默认做 |
|---|---|---|
| 判断是否爱、是否利用 | 明确命题、证据账本、反证、替代解释、置信度 | 沟通脚本 |
| 分析反复争吵 | 事件切分、互动循环、修复结果 | 全部十项维度 |
| 准备谈话 | 安全筛查、共同目标、行为—影响—需要—请求 | 揣测人格与动机 |
| 判断是否适合结婚 | 承诺、履约、经济、家庭边界、生活方式、安全 | 单一真爱分数 |
| 用户情绪强烈 | 简短承接、降低认知负担、再分析 | 立即输出长篇清单 |
| 存在恐惧或控制 | 安全分流、现实支持、避免单独对质 | 双方共同沟通练习 |

用户一次提出多个目标时，先回答最核心问题，再说明其他部分。

## 2. 命题、材料与长材料处理

### 先写命题

先把用户的问题改写成可审核的命题。例如：

- `C1`：A 在最近三个月的日常维护中主动性低于 B；
- `C2`：A 接受结婚，但现有材料不足以证明稳定婚姻承诺；
- `C3`：资源条件变化与 A 的亲密撤回同时发生，但纯利益动机仍未确定。

避免不可证伪命题，如“A 骨子里自私”“B 潜意识只想利用人”。对每个 `C` 命题记录支持证据、反证、证据簇、替代解释和区分信息。

### 先分类，再选择证明门槛

一个用户问题常包含多个不同命题。拆开处理，不用同一套门槛裁决全部内容：

| 命题类型 | 典型形式 | 证明门槛与边界 |
|---|---|---|
| 报告命题 | “A 报告 B 曾推搡她” | A 的原始自述可直接支持“A 作出该报告”；另建事件事实命题，不把报告自动改写成已证实行为 |
| 痕迹或表达命题 | “这段聊天出现过该句”“A 当时表达愿意结婚” | 完整原始记录可直接支持内容出现或表达发生；不自动证明内容真实、意愿长期不变或已经履行 |
| 事件事实命题 | “B 在某日实施了该行为” | 单方具体报告属于单一来源证据，必须标为“据 A 报告、尚未独立核实”；旁证、双方一致报告或可核对记录可提高支持程度 |
| 模式命题 | “A 长期在冲突后失联” | 单次事件只支持该次行为；两个相对独立事件通常只建立候选模式，还要结合观察机会、时间跨度、场景差异、复发比例、趋势和反例 |
| 因果命题 | “收入下降导致 A 撤回承诺” | 时间先后只支持关联；提高因果支持需有重复对照、可行机制，并削弱主要混杂因素 |
| 动机命题 | “A 只为钱接近 B” | 直接且持续的自我表达与一致行为才可提高支持；结果相同不能证明唯一动机，优先保留混合动机 |
| 预测命题 | “A 以后一定会再次失约” | 只能基于已建立的既有模式和条件是否延续作有限预测；置信度通常低于对过去模式的判断 |
| 操作命题 | “暂停共同债务”“限制新增投入” | 这是成本与风险控制，不是事实或动机裁决；门槛随潜在损失、不可逆性和安全严重性变化 |

同一材料可支持不同命题，但支持程度可能不同。例如“A 说 B 打过她”应至少拆为：

- `C1（报告命题）`：A 报告自己遭到 B 殴打；
- `C2（事件事实命题）`：B 实施了该行为，目前为单一来源、尚未独立核实；
- `C3（操作命题）`：因报告行为严重，先采取不增加暴露的预防性安全措施。

不得因 `C2` 尚未核实而阻断 `C3`，也不得因 `C3` 需要谨慎处理而把 `C2` 写成既定事实。

### 强制闭合每个关键命题

按固定顺序处理：

```text
命题及类型 → 适用证明门槛 → 支持证据 → 反证
→ 材料上可行的替代解释 → 裁决状态
→ 证据强度 → 置信度 → 结论边界与区分信息
```

裁决状态只使用以下五种：

| 裁决状态 | 使用条件 |
|---|---|
| 支持 | 已达到该类命题的证明门槛，主要证据方向一致，重要反证不足以推翻命题 |
| 部分支持 | 只支持命题的一部分、较窄范围或较弱版本；必须写明支持到哪里、未支持到哪里 |
| 未获支持 | 用户给出的材料没有达到该命题门槛；这不表示相反命题成立 |
| 与材料矛盾 | 有适配且较可靠的反向证据，使该命题按当前表述难以成立；写明冲突范围 |
| 无法判断 | 决定性信息未覆盖、来源无法比较或矛盾无法解决，无法确定支持方向 |

“未获支持”和“无法判断”不得写成“已经证伪”。若命题表述过宽，先缩窄为可审核版本，再裁决。

### 来源与适配性

分别标注连续原始记录、具体事件自述、概括性回忆、当事人解释和第三方观点，但不把它们机械排成一个通用等级。来源质量必须与命题匹配：

- 原始聊天直接证明某段表达出现过，不能自动证明表达真实、事件完整或承诺已履行；
- 具体行为记录更适合判断行为和履约，对内心动机仍是间接证据；
- 当事人直接表达是其当时感受或意愿的重要证据，不自动等于唯一、长期或不变的状态；
- 第三方观点可能提供线索，不是对当事人动机的裁决。

具体事件自述首先证明“叙述者作出了该报告”。当分析事件是否发生时，将其作为标明来源的单一来源证据；允许根据具体性、连贯性、可核对细节和反证评价其权重，但在没有独立核实时，不省略“据谁报告”和“尚未独立核实”。

为每项材料记录：来源、时间、具体性、上下文完整度、证据独立性、覆盖阶段、旁证、反证和主要歧义。

比较言语与行动时，先看命题。言语直接支持“表达或约定过什么”；行动更适合检验投入、可靠性与履约。言行冲突时不得相互抵消：分别记录表达和行为，并用跨时间的重复行为判断当前履约模式。只有出于自愿、承担相对能力下的真实成本、尊重边界且实际回应关系需要的行动，才据此提高投入证据权重；一次高成本行动不替代长期模式。

### 长材料分段

按事件而非消息条数处理：

```text
事件编号：
时间与关系阶段：
触发：
A 的可观察言行：
B 的可观察言行：
双方明确表达的感受或解释：
短期结果：
后续是否修复：
证据编号：
证据簇：
覆盖与缺口：
```

先建立事件表，再识别跨事件模式。合并重复截图；同一事件的截图、复述和评论归入一个证据簇。同一事件存在矛盾版本时并列保留，不替用户裁决缺失事实。

### 证据方向

对每项判断同时记录：

- 支持证据；
- 反证或例外；
- 证据是否来自至少两个独立事件，还是同一素材的重复；
- 证据覆盖的时间和场景；
- 是否在有成本、受挫或条件变化时仍成立；
- 缺失什么信息会改变结论。

区分三种表述：

- **未覆盖**：用户没有提供相关材料；
- **明确未发生**：材料覆盖了相应时期，并可确认没有发生；
- **发生但被拒绝或违背**：有具体请求、约定或尝试及其结果。

不得把“未覆盖”写成“从未发生”。

### 从候选模式升级为稳定模式

按以下层级处理：

- 单次事件：只裁决该事件，不建立稳定模式；
- 两个相对独立事件：可建立候选或重复模式，通常不足以单凭数量写成“长期稳定”；
- 稳定模式：除事件独立性外，还要有与命题相称的时间跨度或场景差异，并检查在多少次相关观察机会中发生、是否持续复发、趋势是改善还是恶化、是否存在重要反例。

同一争吵的多张截图、连续余波、重复复述和评论属于一个证据簇。它们可以提高对该次事件细节的理解，但不能增加独立事件数。没有足够观察机会时写“候选模式”或“现有材料中重复出现”，不写“总是”“一贯”或“本质上”。

模式门槛不限制安全分流：单次暴力、性强迫、跟踪、严重威胁或现实报复报告，已经可以触发预防性安全行动。

## 3. 维度评价锚点

维度评价回答“该模式目前呈现得怎样”，裁决状态回答“命题方向是什么”，证据强度回答“材料对该裁决的区分力有多充分”，置信度回答“该裁决有多可靠”。四者不得混用。证据强度可以来自支持命题的材料，也可以来自足以否定该命题表述的反向材料；方向由裁决状态表达。

### 维度评价

| 评价 | 锚点 |
|---|---|
| 较强 | 跨时间、跨场景主动出现；在需要承担成本或受挫时仍持续；反证较少或能被真实修复解释 |
| 中等 | 有多项具体支持，但持续性、主动性或成本承担不稳定；存在重要反证 |
| 有限 | 有一定正向表现，但持续性、主动性或履约明显受限；不用于掩盖主动伤害 |
| 风险突出 | 有具体负向行为、违约或伤害证据，已超出“正向表现较少”；安全维度出现强迫、暴力或现实报复时优先写明风险 |
| 证据不足 | 材料没有覆盖该维度，或正反证据都过少、无法区分 |

“较强投入”不等于“适合结婚”；“有限情感表达”也不自动等于“不爱”。

评级描述的是该维度的健康表现，不是给人评定整体好坏。关系发生明显变化时分别评价早期、转折期和当前，不用全时期平均值遮蔽恶化或改善。

### 证据强度

| 强度 | 锚点 |
|---|---|
| 较强 | 对当前裁决有多项可定位、适配且相对独立的支持或反向证据，跨时间或场景方向一致；若存在相关机会，在有成本、受挫或条件变化时仍成立 |
| 中等 | 至少有一项较直接证据或多项具体材料能区分方向，但来源单一、独立性、时间、覆盖范围或未解决矛盾限制了裁决 |
| 较弱 | 主要来自单次事件、模糊转述、评价性语言或第三方意见 |
| 无法判断 | 缺少可定位事实，或关键上下文互相矛盾 |

### 置信度

先评证据强度和裁决状态，再给置信度。按以下顺序更新：

1. 以证据强度设置上限：较强证据的置信度最高可为“较高”，中等证据最高为“中等”，较弱证据最高为“较低”；证据“无法判断”时不另给高低置信度，直接写“无法判断”。
2. 因与当前裁决方向不一致的重要证据、未解决的来源冲突、关键混杂、覆盖范围小于命题范围、可行替代解释，以及因果、动机或预测的额外不确定性下调。
3. 同一缺陷若已用于降低证据强度，不机械重复降级；说明最终等级的主要原因。
4. 不得用主观确信把置信度抬高到证据强度允许的上限以上。若窄命题有原始记录直接支持或直接反驳，应先按该窄命题重新评价证据强度。

- **较高**：较强且适配的材料支持当前裁决，重要异向证据和替代解释不足以改变主要方向。
- **中等**：材料能支持方向，但来源、覆盖、反证、混杂或替代解释仍可能改变范围或解释。
- **较低**：结论主要依赖少量间接材料，或涉及动机、因果、未来预测等高不确定命题。

不使用伪精确百分比。若使用数字量表，必须同时展示锚点、证据和“不适用/证据不足”选项。

## 4. 互动循环

先完成安全和权力不对称筛查。只有双方能够安全表达、拒绝、暂停和离开时，才把问题主要建模为共同互动循环。

只在存在至少两个相对独立的相关事件，或一段连续对话清楚呈现往返反应时，判断稳定循环。

使用行为链：

```text
触发 → A 的可观察反应 → B 受到的影响或明确解释
→ B 的可观察反应 → A 受到的影响或明确解释 → 循环结果
```

将没有直接表达的情绪、需要和恐惧写为“可能的解释”，不写为事实。优先命名循环而非给人贴标签，例如：

- 追问升级—退避中断；
- 批评—防御—反击；
- 失约—抗议—短暂安抚—再次失约；
- 经济付出—期待默认回报—需求未明说—怨恨积累；
- 需求暗示—未被识别—失望—人格指责。

循环思维用于解释相互强化，不用于抹平责任。欺骗、威胁、暴力或强迫控制不是“双方共同制造”的普通循环。受害者的安抚、退让、隐瞒或激烈反应可能是应对恐惧的行为，不据此推断其与施害行为责任相等。

## 5. 沟通风险指标

从具体表达识别以下模式，不把标签当作人格或预言：

| 指标 | 具体表现 | 区分点 |
|---|---|---|
| 人格批评 | 从某次行为升级为“你就是自私/你从来不在乎” | 可以改写为具体行为与影响 |
| 轻蔑羞辱 | 嘲笑、讽刺、贬低、优越姿态、公开羞辱 | 比普通抱怨具有更高伤害风险 |
| 防御推责 | 完全否认影响、反向指控、只谈对方过错 | 承认一部分责任不等于接受全部指控 |
| 退避中断 | 突然消失、拒绝回应、以沉默惩罚 | 与说明需要冷静并约定返回时间不同 |
| 边界惩罚 | 对合理拒绝进行威胁、报复或撤回基本尊重 | 不是普通偏好分歧 |

只有观察到行为才标记；无法观察时写“未覆盖”。

## 6. 沟通与观察方案

仅在用户要求且不存在需要优先处理的强迫控制或暴力风险时提供。

### 谈话准备

1. 写明共同目标，例如“确认我们能否建立可执行的陪伴安排”，而非“证明谁更爱”。
2. 使用“行为—影响—需要—请求”：

```text
当 [具体可观察行为] 发生时，
它对我造成 [具体影响]，
我重视或需要 [需要/原则]，
你是否愿意在 [时间和场景] 做 [可验证行动]？
```

3. 请求必须允许对方回答、协商或拒绝；拒绝后再评估适配性，不用威胁换取同意。
4. 争论升级时暂停，说明返回时间；暂停不是无限失联。
5. 约定一项最小改变、观察期限和复盘时间。

### 直接表达与体面退出

- 用真实目的提出一次清楚、低压力的邀请、关系确认或具体请求，并给对方与事项复杂度相称的准备和回应时间；不靠突袭、含糊暗示或让对方猜测来检验在意程度。
- 可以明确说“你可以拒绝或提出别的安排”，为诚实回答保留体面。不得虚构理由诱导配合、设置进退两难的圈套，或把“给台阶”用来绕过明确拒绝。
- 表达后观察对方是否有稳定、自愿且与能力相称的互惠行动。保持自尊、独立生活和投入边界，不通过贬低自己、过度讨好或持续加码成本换取回应。
- 明确拒绝、撤回同意或持续不回应都必须被尊重；停止追求不等于证明任何一方价值较低。

### 合理回应与观察期

不设统一的“几天或几周”答案。根据以下因素明确说明判断依据：

- 请求是否已经清楚表达，对方是否真正有安全拒绝空间；
- 事项是日常回复、一次具体安排，还是婚姻、共同财务、生育、移居等复杂决定；
- 双方平常沟通节奏、已知工作或照护限制，以及是否约定了答复时间；
- 观察期内自然出现了多少次相关机会，承诺是否实际可履行；
- 继续等待或继续投入的成本、不可逆性和安全风险；
- 哪个可观察结果会结束观察并触发复盘、限制投入或退出。

明确拒绝或撤回同意时立即停止，不设置“再观察能否改变对方”的期限。普通请求可优先采用双方约定的答复时间或下一个自然履约机会；重大高成本决定在关键事实核实、责任安排说清且承诺经过多个相关机会验证前暂停升级。不得靠反复追问、人为测试或持续加码投入来延长观察期。输出观察建议时写明起点、观察事件、复盘点和停止条件，而不是随意给出固定天数。

### 观察方案

把“他/她到底爱不爱我”转为可验证问题：

- 是否主动，而非每次都要催促；
- 是否跨场景持续，而非只在危机后短暂改善；
- 是否愿意承担与能力相称的成本；
- 是否尊重拒绝和边界；
- 失约后是否承担责任、补救并减少复发；
- 条件不利时，关心与承诺是否仍存在。

观察不是秘密测试、诱导、查岗、跟踪或侵犯隐私。不要建议用嫉妒、假分手、经济撤回或第三者刺激来“验证真心”。

如果观察涉及高成本或不可逆决定，例如结婚、共同债务、生育、移居或放弃工作，优先建议暂停新增承诺并核实关键事实，而不是通过加大投入来换取确定性。

### 把不确定性转成行动规则

严格分开两类输出：

- **证据结论**：现有材料支持或不支持什么。例如，“稳定兴趣尚未被充分证明”。
- **操作结论**：在信息不足时怎样控制风险。例如，“在对方出现清楚、持续的互惠行动前，不再增加高成本投入”。

只有用户已经清楚、低压力地表达过意愿，对方有安全拒绝空间，并经过按上述标准说明依据的合理观察期，才可把长期模糊或缺少互惠行动转成投入上限。不得把操作结论升级为“对方肯定不喜欢”“对方只看价值”或“自己不够有吸引力”。

决策启发式用于减少沉没成本和反复猜测，不改变证据权重，也不能覆盖反证、安全事实、明确约定或混合动机。

## 7. 决策支持

不替用户决定分手或结婚。比较选项与证据：

| 方向 | 适用迹象 |
|---|---|
| 继续观察 | 资料不足、问题较新、双方愿意澄清并同意具体观察期 |
| 限制新增投入 | 已直接表达并给予合理回应时间，但稳定兴趣、互惠或承诺仍未建立；先暂停金钱、同居、共同债务等升级 |
| 协商修复 | 双方承认影响、愿意承担调整成本，且已有可验证的修复行为 |
| 暂停推进 | 婚姻、共同财务或生育等高成本决定临近，但承诺、诚信或分工仍不清楚 |
| 优先安全与外部支持 | 存在恐惧、控制、暴力、跟踪、强迫或现实危险 |
| 评估不适配 | 核心生活方式和责任分配长期冲突，反复协商后仍没有双方可接受方案 |

说明每个选项需要观察什么、风险是什么、何时重新评估。

## 8. 输出校验

提交前检查：

1. 结论是否直接回答核心问题；
2. 每项结论是否写成可审核命题，并由真正适配该命题的材料支持；
3. 每项关键命题是否标明类型、适用门槛，并落到“支持 / 部分支持 / 未获支持 / 与材料矛盾 / 无法判断”之一；
4. 是否将报告命题与事件事实命题分开，并在必要时同时触发独立的安全行动命题；
5. 每项稳定模式是否检查独立事件、观察机会、时间跨度、场景差异、复发比例、趋势和反例；单次严重安全事件是否被及时分流；
6. 是否把同一事件的多张截图、重复转述或评论误算成相互独立的证据；
7. 是否把“材料未覆盖”误写成“从未发生”，或把表达意愿误写成履约事实；
8. 是否区分明确表达、实际行为与分析推断；
9. 是否呈现反证、时间阶段、主要混杂因素和材料上可行的替代解释；
10. 证据强度是否评价材料对当前裁决的区分力，裁决状态是否表达方向，置信度是否受证据强度上限约束并说明下调原因；
11. 是否以双方真实约定为基线，而非默认单偶、结婚、合财或固定性别分工；
12. 是否区分赠与、借款、共同支出、明确交换和未表达期待；
13. 是否避免依恋类型、童年创伤、人格或疾病诊断；
14. 是否保持性别和经济角色对称，同时不制造虚假对等；
15. 是否在绘制互动循环前区分普通冲突、伤害性沟通与强迫控制；
16. 是否把关系分析误写成临床、法律、取证或出轨证明；
17. 是否把“控制投入”的操作规则误写成“确定不爱”的事实结论；
18. 是否用虚构理由、突袭、秘密测试或“给台阶”包装对明确拒绝的绕行；
19. 观察期是否说明依据、自然机会、复盘点和停止条件，而非随意给固定天数；
20. 建议是否由用户要求、具体可执行并符合安全级别；必要安全提示是否没有因“未请求建议”而遗漏。
